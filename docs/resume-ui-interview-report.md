# `/resume` UI Interview Report

วันที่สัมภาษณ์: 14 กรกฎาคม 2026  
จำนวนคำถาม: 12 ข้อ  
วัตถุประสงค์: กำหนดทิศทางการปรับปรุง UI ให้ immersive, ใช้งานง่าย และมีภาพลักษณ์พร้อมใช้งานจริงในระดับ production

## สรุปทิศทางหลัก

หน้า `/resume` ควรสร้างความรู้สึกแรกว่า “ว้าวและอยากเลื่อนดูต่อ” โดยเล่าเรื่องตัวตนของผู้สมัครผ่าน personal story เป็นแกนหลัก ไม่เน้นความเป็น tech หรือ sci-fi แต่ใช้ภาพลักษณ์แบบ premium + emotional ที่ใส่ใจ micro detail

กลุ่มผู้ชมหลักคือผู้ชมทั่วไป อาจารย์ และบริษัทด้านการศึกษา เช่น บริษัท นิว จีเนียส กรุ๊ป จำกัด ซึ่งกำลังมองหา Staff สำหรับงานอีเวนต์เยาวชน เป้าหมายสำคัญคือทำให้ผู้ชมเห็นศักยภาพในการทำงานหน้างาน การดูแลน้อง ๆ การประสานงาน และการรับมือกับสถานการณ์กดดันได้อย่างเป็นระบบ

## เป้าหมายของผู้ชมและผลลัพธ์ที่ต้องการ

- ผู้ชมต้องเข้าใจตัวตนและศักยภาพของผู้สมัครโดยไม่ต้องอ่านเนื้อหาที่ยาวเกินจำเป็น
- ผู้ชมต้องเห็นความเป็นมิตร ความรับผิดชอบ การวางแผน และการแก้ปัญหาเฉพาะหน้า
- หน้าเว็บต้องชวนให้เลื่อนต่ออย่างเป็นธรรมชาติ โดยยังอ่านง่ายบนมือถือ
- เมื่อดูจบ ผู้ชมควรติดต่อผ่านโซเชียลมีเดียได้ทันที
- ช่องทางที่ต้องมี: Instagram, Facebook, YouTube, LinkedIn และ GitHub
- ไม่ต้องเพิ่ม CTA ข้อความใหม่สำหรับการติดต่อ

## Positioning ของผู้สมัคร

ผู้สมัครเป็นนักศึกษาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยสงขลานครินทร์ (PSU) ชั้นปีที่ 2 ที่มีประสบการณ์จากกิจกรรมหาดใหญ่ Open House 2026 เมื่อวันที่ 4 กรกฎาคม 2026 โดยทำหน้าที่เป็นพี่เลี้ยง ซัพพอร์ตกิจกรรมตลอดวัน และประจำฐานวิศวะ

จุดแข็งที่ควรสื่อสารผ่านหน้าเว็บ:

- เตรียมอุปกรณ์และตรวจความพร้อมของงาน
- ประสานงานกับหลายส่วนและช่วยรันคิว
- คุยกับคนได้หลายประเภท มีอัธยาศัยดี และรับฟังผู้อื่น
- คิดเป็นลำดับขั้นตอนและวางแผนงานตามกรอบเวลา
- แก้ปัญหาหน้างานโดยประเมินทางเลือกและ trade-off ก่อนตัดสินใจ
- อธิบายเรื่องยากด้วยการแบ่งเป็น 3 ประเด็นหลัก แล้วค่อยขยายรายละเอียด
- ปรับระดับภาษาให้เหมาะกับผู้ฟัง
- มีน้ำเสียงนุ่ม เป็นมิตร และสามารถดึงความสนใจบนเวทีได้เมื่อเตรียมตัว
- ใส่ใจความเป็นระเบียบ ความถูกต้อง และรายละเอียดเล็ก ๆ ของงาน
- ต้องการพัฒนา soft skills ด้านการพูด การจัดการ การบริหาร ความรับผิดชอบ และการกล้าแสดงออก

## แนวทางการเล่าเรื่อง

ใช้ personal story เป็นโครงสร้างหลัก เพราะปัจจุบันมีประสบการณ์งานอีเวนต์หลักหนึ่งงาน โดยแบ่งเนื้อหาให้ผู้ชมเห็นภาพดังนี้:

1. ตัวตนและพื้นฐาน: นักศึกษาวิศวะคอมปี 2 ที่สนใจการเรียนรู้และการทำงานกับผู้คน
2. เหตุผลที่เหมาะกับงาน Staff: เป็นระบบ รับผิดชอบ สื่อสารได้ และพร้อมช่วยให้งานเดินต่อ
3. ประสบการณ์จริง: หาดใหญ่ Open House 2026 และบทบาทพี่เลี้ยง/ผู้ดูแลฐานวิศวะ
4. วิธีคิดหน้างาน: ประเมินปัญหา → สร้างทางเลือก 2–3 ทาง → พิจารณา trade-off → ตัดสินใจภายในเวลาที่เหมาะสม
5. สิ่งที่อยากพัฒนาต่อ: การพูด การจัดการ การบริหาร และการทำงานร่วมกับผู้คน

ในอนาคต หากมีประสบการณ์หลายงาน ค่อยขยายโครงสร้างไปเป็น timeline หรือ case study หลายเหตุการณ์ได้

## Visual direction

### อารมณ์และภาพรวม

- Premium แต่ไม่ห่างเหิน
- Emotional แต่ไม่ดราม่าหรือครินจ์
- มีความอบอุ่น เป็นมนุษย์ และน่าเชื่อถือ
- ไม่ใช้ภาพลักษณ์ tech, sci-fi หรือล้ำเกินบริบท
- สร้างความรู้สึกว่าออกแบบอย่างตั้งใจผ่าน spacing, typography, crop, alignment และรายละเอียดเล็ก ๆ

### สื่อภาพ

ควรใช้ภาพจริงจากกิจกรรมเป็นแกน ได้แก่:

- ภาพขณะทำหน้าที่พี่เลี้ยง
- ภาพการสัมภาษณ์บนเวทีที่เห็นผู้สมัครอยู่ในเฟรม
- ภาพมุมกว้างจากเวทีที่เห็นน้อง ๆ เป็น foreground

แนวคิดเพิ่มเติมคือใช้ AI สร้างวิดีโอสั้นความยาวประมาณ 5–10 วินาทีจากภาพจริง แล้วทำเป็น loop เพื่อเพิ่มความ immersive โดยควรคงภาพลักษณ์ที่เป็นธรรมชาติและไม่ทำให้เหตุการณ์ดูเกินจริง

### Motion และ interaction

ผู้ใช้ต้องการ:

- การเล่าเรื่องตามจังหวะ scroll
- typography ที่เคลื่อนไหว
- cursor interaction
- transition ระหว่าง section
- ภาพถ่ายจริงและวิดีโอ loop

ตัดฟีเจอร์เสียงออกแล้ว เพื่อไม่รบกวนผู้ใช้และลดความซับซ้อนในการใช้งาน

## UX และ responsive requirements

- มือถือต้องอ่านง่าย เลื่อนต่อเนื่อง และใช้งานได้ทันที
- ยังคงความ immersive และสร้าง first impression ที่ดีบนหน้าจอเล็ก
- Interaction ต้องไม่ทำให้ผู้ใช้ต้องเดาวิธีใช้งาน
- ลำดับเนื้อหาต้องชัดเจนแม้ผู้ใช้จะอ่านแบบกวาดสายตา
- เนื้อหาในแต่ละพื้นที่ต้องพอดีกับขนาด component
- Card ที่มีพื้นที่สำหรับ 4–5 บรรทัดควรมีข้อความยาวพอดี ไม่สั้นจนเกิดพื้นที่ว่างโดยไม่จำเป็น
- หลีกเลี่ยงข้อความที่ดูเบียว ครินจ์ หรือมีลักษณะ AI-slop
- ต้องตรวจความยาวของข้อความทั้งภาษาอังกฤษและภาษาไทย เพราะภาษาไทยอาจมีความสูงของบรรทัดและการตัดคำต่างกัน

## สิ่งที่ต้องรักษาไว้

- Color palette เดิม
- Font style เดิม
- Navbar
- ปุ่มเปลี่ยนภาษา EN/TH
- ปุ่มเปลี่ยนธีม
- Sections: About, Features และ Contact
- Section navigation
- เนื้อหาที่มีความเป็นตัวตนและอธิบายประสบการณ์จริง

การปรับปรุงควรเน้นการจัดวาง ลำดับการเล่าเรื่อง ภาพประกอบ และคุณภาพของ micro detail โดยไม่เปลี่ยนเอกลักษณ์หลักของหน้าเดิม

## Content guardrails

- เขียนจากประสบการณ์จริงและใช้ภาษาที่มั่นใจแบบเป็นธรรมชาติ
- แสดงความสามารถโดยอ้างอิงพฤติกรรมหรือวิธีทำงาน ไม่ใช้คำโฆษณากว้าง ๆ
- หลีกเลี่ยงการกล่าวเกินจริงว่าเป็นผู้เชี่ยวชาญหรือมีประสบการณ์มากกว่าที่มี
- ใช้ตัวอย่างอุปกรณ์พังและการจัดสรรโควต้าเวลาเป็นหลักฐานของการแก้ปัญหาได้ หากพื้นที่เหมาะสม
- แยก “สิ่งที่ทำแล้ว” ออกจาก “ทักษะที่กำลังพัฒนา” ให้ชัดเจน
- ตรวจคำไทยและ encoding ให้แสดงผลถูกต้องทั้งหน้า เพราะข้อความภาษาไทยในหน้าเดิมมีความเสี่ยงเรื่อง encoding เพี้ยน

## ลำดับความสำคัญสำหรับการออกแบบ

### P0 — ต้องได้

- First impression ที่ทำให้รู้สึกอยากเลื่อนต่อ
- Personal story ที่เข้าใจง่ายและเชื่อมกับบทบาท Staff
- อ่านง่ายและใช้งานได้ดีบนมือถือ
- คง palette, fonts, navbar, language/theme toggle และ section navigation
- แสดง social links ทั้ง 5 ช่องทาง
- ไม่มีเสียงอัตโนมัติ

### P1 — ควรมี

- ภาพจริงจาก Open House
- วิดีโอ loop 5–10 วินาทีที่สร้างจากภาพกิจกรรม
- Scroll storytelling และ typography motion ที่ช่วยเล่าเรื่อง
- Micro detail ที่ทำให้ภาพรวมดู premium
- Cursor interaction และ section transition ที่ไม่รบกวนการอ่าน

### P2 — พิจารณาภายหลัง

- ขยายเป็น timeline หรือ case study เมื่อมีประสบการณ์เพิ่ม
- เพิ่มเหตุการณ์หรือผลงานอีเวนต์อื่นเพื่อเปรียบเทียบวิธีทำงาน

## Definition of done ด้านประสบการณ์

ถือว่าทิศทางการปรับปรุงตอบโจทย์เมื่อผู้ชมสามารถ:

1. เข้าใจได้ในช่วงแรกว่าผู้สมัครเป็นใครและสนใจอะไร
2. เห็นความเหมาะสมกับงาน Staff จากประสบการณ์และวิธีคิดจริง
3. เลื่อนอ่านต่อได้โดยไม่รู้สึกว่าถูก animation ขัดจังหวะ
4. อ่านเนื้อหาบนมือถือได้โดยไม่เจอ card ที่ข้อความสั้นหรือยาวเกินพื้นที่
5. เข้าถึง Instagram, Facebook, YouTube, LinkedIn และ GitHub ได้ง่าย
6. จดจำภาพลักษณ์ว่าเป็นคนมีระบบ เป็นมิตร ใส่ใจรายละเอียด และรับมือกับสถานการณ์จริงได้

## คำถามที่ยังควรตัดสินใจก่อนลงมือออกแบบ

- จะใช้ภาพถ่ายจริงภาพใดเป็น hero และภาพใดเป็น supporting visual
- วิดีโอ AI loop แต่ละชิ้นจะใช้กับ section ใด และต้องมีการระบุว่าเป็นวิดีโอที่สร้างจากภาพจริงหรือไม่
- Social links จริงของทั้ง 5 ช่องทางคือ URL ใด
- ต้องการให้ภาษาไทยเป็นภาษาหลักของหน้า `/resume` หรือคง English เป็นค่าเริ่มต้น
- ลำดับความสำคัญของเรื่องเล่า: ตัวตน, Open House, วิธีคิดแก้ปัญหา หรือเป้าหมายการพัฒนาตัวเอง
